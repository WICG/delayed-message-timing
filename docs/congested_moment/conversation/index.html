Opening a long email conversation

Send 100 synthetic email bodies to a dedicated worker in a burst. Each handler extracts preview text and simulates about 3 ms of CPU work. This is not a network or database benchmark.

For actual worker LoAF entries, use a Chromium build with the experimental implementation and --enable-blink-features=LongAnimationFrameWorker. Serve this folder over HTTP, not a file: URL.
